============================================================
3. PITCH DU JEU
============================================================

Le joueur contrôle NYR, une petite créature astrale de type dragon-serpent.
NYR avance en permanence, absorbe des fragments d’énergie, grandit, évolue visuellement et tente de survivre le plus longtemps possible.

Boucle centrale :
DÉPLACER -> ABSORBER -> GRANDIR -> ÉVOLUER -> SURVIVRE -> BATTRE SON RECORD -> REJOUER

Objectif produit :
- jeu très simple à comprendre ;
- parties rapides à relancer ;
- sensation de croissance très visible ;
- difficulté créée en grande partie par la réussite du joueur : plus NYR grandit, plus il devient difficile à manœuvrer.

============================================================
4. NYR — IDENTITÉ VISUELLE
============================================================

Nature :
- créature astrale ;
- mélange de dragon-serpent, anguille cosmique et esprit nocturne ;
- éviter le serpent réaliste et le dragon chinois classique.

Silhouette :
- tête unique immédiatement reconnaissable ;
- corps long et fluide ;
- segments organiques légèrement espacés ;
- énergie visible entre certains segments ;
- mouvement ondulant.

Palette de base :
- corps noir bleuté / anthracite ;
- lueurs violet, bleu électrique et cyan léger ;
- yeux très lumineux ;
- accents dorés très discrets uniquement sur la forme finale.

Personnalité visuelle :
- mignon au départ ;
- élégant et mystérieux ensuite ;
- majestueux et légèrement inquiétant dans sa forme finale.

Absorption :
- un nouveau segment apparaît avec un petit flash lumineux ;
- il rejoint la queue et s’intègre naturellement à l’ondulation générale.

Mort :
- aucune violence graphique ;
- NYR se désagrège en fragments et poussière astrale.

============================================================
5. LES 4 FORMES DE NYR
============================================================

FORME I — L’ÉCLAT
Seuil : 0 à 19 fragments.
- petite tête arrondie/légèrement triangulaire ;
- deux mini-cornes ;
- grands yeux lumineux ;
- corps très simple ;
- petite queue en pointe ;
- faible aura et petites particules.

FORME II — LE SPECTRE
Seuil : 20 à 49 fragments.
- tête un peu plus allongée ;
- cornes plus visibles ;
- petites nageoires/ailerons latéraux ;
- lignes lumineuses sur le corps ;
- traînée plus présente.

FORME III — LE NOCTURNE
Seuil : 50 à 99 fragments.
- tête affirmée ;
- cornes plus longues/courbées ;
- regard plus intense ;
- plaques ou écailles lumineuses ;
- petites ailes/membranes spectrales décoratives ;
- impulsions lumineuses lors des absorptions.

FORME IV — LE DÉVOREUR
Seuil : 100 fragments et plus.
- grande tête majestueuse ;
- cornes développées ;
- yeux intenses ;
- ailes spectrales plus lisibles ;
- lignes lumineuses sur le corps ;
- crêtes/pointes fines sur certains segments ;
- accents dorés discrets ;
- queue spectaculaire ;
- aura légère et circulation d’énergie visible.

La partie continue après la Forme IV : aucune fin automatique à 100 fragments.

============================================================
7. OBJETS / ABSORPTIONS V1
============================================================

FRAGMENT NORMAL
- +100 points
- +1 segment
- ressource principale, apparition fréquente

ORBE RARE
- +400 points
- +3 segments

ÉNERGIE
- +200 points
- boost de vitesse temporaire d’environ 3 secondes

ÉCLAT RARE
- +1000 points
- récompense rare ; ne doit pas rallonger excessivement le corps

FRAGMENT PUR
- restaure environ +20 % de stabilité
- maximum 100 %

CORRUPTION
- élément dangereux
- retire environ 20 % de stabilité

============================================================
8. CROISSANCE / LONGUEUR
============================================================

Départ : environ 3 segments.

Principe :
- la longueur grandit avec les absorptions ;
- la croissance doit être immédiatement visible ;
- éviter une longueur techniquement infinie qui pénaliserait les performances mobiles.

Direction V1 :
- longueur visuelle maximale autour de 120 segments ;
- au-delà, le score et la progression continuent même si le nombre de segments affichés plafonne.

============================================================
9. VITESSE / DIFFICULTÉ
============================================================

Courbe de vitesse de départ envisagée :
- début : 100 %
- 25 fragments : 105 %
- 50 fragments : 110 %
- 75 fragments : 115 %
- 100 fragments : 120 %
- 150 fragments : 125 %
- plafond visé : environ 130 %

Principe :
- ne pas rendre le jeu difficile uniquement par une vitesse excessive ;
- la longueur, les obstacles, la corruption et l’espace disponible doivent être les principales sources de tension.

============================================================
10. STABILITÉ / COLLISIONS
============================================================

NYR possède une jauge STABILITÉ.
Départ : 100 %.

Valeurs V1 de travail :
- collision avec obstacle : -25 % ;
- collision avec son propre corps : -15 % ;
- corruption : -20 % ;
- gros danger exceptionnel : jusqu’à -35 % si retenu plus tard ;
- fragment pur : +20 %.

Game over uniquement lorsque STABILITÉ atteint 0 %.

Direction importante :
- éviter la mort instantanée au premier contact comme dans Snake classique ;
- laisser au joueur une possibilité de récupération et de sauvetage de partie.

============================================================
11. ZONES D’UNE PARTIE
============================================================

La partie reste continue, sans chargement entre les zones.
Le décor et l’ambiance évoluent progressivement.

ZONE 1 — ESPACE NOCTURNE
0 à 24 fragments.
- apprentissage ;
- peu d’obstacles ;
- ambiance calme.

ZONE 2 — NÉBULEUSE
25 à 59 fragments.
- premiers obstacles mobiles ;
- corruption occasionnelle ;
- ambiance plus dense.

ZONE 3 — FAILLE ASTRALE
60 à 99 fragments.
- davantage d’obstacles ;
- zones dangereuses ;
- vitesse supérieure ;
- tension accrue.

ZONE 4 — LE VIDE
100 fragments et plus.
- Forme IV atteinte ;
- tous les dangers V1 peuvent apparaître ;
- densité qui continue à augmenter progressivement ;
- survie et record sans limite de score imposée.

Chaque changement de zone doit pouvoir être signalé visuellement sans interrompre la partie.

============================================================
12. SCORE / COMBO
============================================================

Le score vient principalement des objets absorbés.

Multiplicateur de série sans dégâts envisagé :
- 10 objets sans dégâts : x1,25
- 25 objets : x1,50
- 50 objets : x2
- 100 objets : x3

Une collision remet le multiplicateur à x1.

But :
- permettre de jouer simplement pour survivre ;
- récompenser aussi les joueurs cherchant un record propre et maîtrisé.

20B. CONTRÔLE / VIRAGE — DIRECTION VALIDÉE
============================================================

Décision validée le 09/09/2026 :
- Le virage de NYR est LIMITÉ : aucun demi-tour instantané à 180°.
- NYR peut tourner franchement, mais sa trajectoire doit rester fluide et organique.
- La tête dirige ; le corps suit avec retard le chemin parcouru.
- Le rayon de virage augmente légèrement avec la croissance / les formes de NYR afin que sa taille se ressente dans le pilotage.
- Le contrôle mobile reste : toucher/glisser pour indiquer la direction, sans joystick permanent.
- Le contrôle PC reste : souris en principal, clavier possible en alternative.
- Le Dash conserve le contrôle de direction, mais avec un virage légèrement plus large pendant l'accélération.
- Objectif : éviter les demi-tours artificiels, limiter les collisions absurdes avec le propre corps de NYR et renforcer la sensation de créature vivante.

Valeurs exactes d'angle/vitesse de rotation : À RÉGLER PLUS TARD PAR TEST DE GAMEPLAY, sans coder pour l'instant.
