============================================================
1. OBJECTIF UNIQUE DU PACK 8
============================================================

Implémenter la première évolution VISUELLE de Nyr :

FORME I — ÉCLAT
- reste affichée de 0 à 19 Fragments normaux absorbés.

FORME II — LE SPECTRE
- devient le rendu actif dès la 20e absorption réelle ;
- reste active à 21 et au-delà ;
- ne se redéclenche pas plusieurs fois ;
- ne modifie PAS le gameplay dans ce pack.

Le compteur interne et le seuil one-shot existent déjà depuis PACK 7.
Ne créer aucun second compteur parallèle.
Ne déduire la forme ni du nombre de segments ni du score.

============================================================
2. RÉFÉRENCE CANONIQUE SPECTRE
============================================================

Respecter la direction canonique existante pour la Forme II — Le Spectre :
- tête un peu plus allongée ;
- cornes plus visibles ;
- petites nageoires/ailerons latéraux ;
- lignes lumineuses sur le corps ;
- traînée plus présente.

Le rendu doit rester cohérent avec l'identité actuelle de NYR :
- base sombre anthracite / bleu-noir ;
- violet ;
- bleu électrique / cyan lumineux ;
- style astral lisible sur fond sombre.

Les références visuelles présentes dans `assets/images/references/` peuvent être consultées pour rester cohérent avec la direction officielle.

IMPORTANT :
- rester sur des primitives canvas pour ce prototype ;
- ne pas générer, importer ou fabriquer de nouveaux assets dans ce pack ;
- ne pas chercher le rendu final commercial ;
- le but est de rendre la différence Éclat / Spectre immédiatement lisible et propre.

============================================================
3. ARCHITECTURE ATTENDUE
============================================================

Faire le minimum propre nécessaire.

Préférence :
- conserver `nyrProgression.js` comme source de vérité du compteur de fragments ;
- exposer ou dériver proprement la forme courante à partir du seuil existant ;
- éviter tout état de forme dupliqué susceptible de se désynchroniser ;
- le renderer choisit le rendu Forme I ou Forme II à partir de cet état de progression ;
- le mouvement reste totalement indépendant de la forme dans ce PACK 8.

Il est acceptable soit :
- d'étendre proprement `nyrRenderer.js`,
soit
- de créer un petit module de rendu Spectre dédié si cela rend le code plus clair.

Ne pas faire de refactor général.
Ne modifier que les fichiers indispensables.

============================================================

============================================================

Avant 20 fragments :
- rendu Éclat actuel conservé ;
- tête actuelle ;
- petites cornes ;
- corps actuel ;
- aucune caractéristique Spectre visible prématurément.

NE PAS ajouter dans ce PACK 8 :

============================================================

Aucun bonus de gameplay lié à Spectre.

============================================================
